# 🐱 Kitty Config — Minimal Blue

Minimal, dark blue config for Kitty terminal.

## Features
- Deep blue background (`#1a2332`)
- Good contrast (`#d8dee9`)
- Smooth cursor trail
- Powerline-style tabs
- Transparency support

## Colors
| Role | Hex |
|------|-----|
| Background | `#1a2332` |
| Foreground | `#d8dee9` |
| Accent | `#5294e2` |
| Red | `#bf616a` |
| Green | `#a3be8c` |
