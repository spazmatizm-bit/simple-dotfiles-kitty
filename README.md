# 🐱 Kitty Config — Minimal Blue

Minimal, dark blue config for [Kitty](https://sw.kovidgoyal.net/kitty/) terminal.

Designed for users who want a **clean, eye-friendly** terminal with:
- Deep blue background
- Good contrast
- Smooth cursor trail
- Powerline-style tabs
- Transparency support (via compositor)

---

## 🎨 Colors

| Role        | Hex       |
|-------------|-----------|

| Foreground  | `#d8dee9` |

| Red         | `#bf616a` |
